# i-db 브랜드

마크는 데이터베이스 원통(위 타원 하나, 아래 호 둘)을 `i` 의 몸통으로, 그 위 점을 `i` 의 점으로 둔다. 점만 강조색이다. 글자표(wordmark)는 D2Coding Bold 로 쓴 `i-db` 이고 가운데 `-` 만 강조색이다. 장식(그라데이션·그림자·테두리 상자)은 쓰지 않는다. 단, 앱 아이콘은 Dock 의 다른 앱과 어울리게 판에 옅은 명암과 그림자를 둔다.

| 이름 | 값 | 쓰는 곳 |
| --- | --- | --- |
| 바탕 | `#0a0a0a` | 어두운 바탕, 앱 아이콘 바탕 |
| 잉크(밝은 바탕) | `#0a0a0a` | 밝은 바탕 위 마크·글자 |
| 잉크(어두운 바탕) | `#f0f0f0` | 어두운 바탕 위 마크·글자 |
| 강조 | `#0d9488` | 마크의 점, 글자표의 `-`, 화면의 주 버튼·초점 고리·고른 탭 밑줄·고른 줄(16% 옅게)·진행 표시 |

강조색은 한 화면에 한 번만 눈에 띄게 쓴다. `#0d9488` 은 흰 바탕에서 3.7:1, `#0a0a0a` 바탕에서 5.5:1 이라 두 바탕 모두에서 큰 글자·도형으로 읽힌다(본문 글자색으로는 쓰지 않는다).

| 파일 | 내용 |
| --- | --- |
| `mark.svg` · `mark-dark.svg` | 마크 64×64(밝은·어두운 바탕). 선 굵기는 64 격자에서 4, 16px 에서 1px 이다 |
| `wordmark.svg` · `wordmark-dark.svg` | 글자표. D2Coding Bold 윤곽이라 글꼴이 없어도 같다 |
| `lockup.svg` · `lockup-dark.svg` | 마크 + 글자표 가로 묶음(README 머리) |
| `app-icon.svg` | macOS 앱 아이콘 원본 1024. 824 둥근 사각(반지름 185)에 위아래로 옅은 명암(#262a29→#0a0a0a)·가장자리 1px 빛·아래 그림자를 두고 마크를 키워 얹는다. `packaging/macos/AppIcon.png` 는 이것을 1024px(투명 바탕)로 그린 것이다 |
| `mark-body.svg` · `mark-dot.svg` | GUI 가 마크를 두 색으로 겹쳐 그리는 단색 조각(GPUI 의 svg 는 한 색으로만 칠한다) |

마크 둘레에는 마크 높이의 1/4 만큼 비워 둔다. 마크를 늘이거나 돌리거나 색을 바꾸지 않는다. 16px 보다 작게 쓰지 않는다.

글자 윤곽은 `crates/idb-gui/assets/fonts/D2CodingBold-Ver1.3.2-20180524.ttf`(SIL OFL 1.1)에서 뽑았다.
